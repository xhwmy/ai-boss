# BOSS 直聘 AI 自动投递助手

> 自动搜索 BOSS 直聘岗位 → AI 分析 JD 匹配度 → 自动投递合适岗位

Windows · Python 3.10+ · 兼容 OpenAI 的模型接口 · KIMI Webbridge 浏览器扩展

## ✨ 功能特性

- 🔍 **智能搜索**：多关键词搜索 + 网页原生筛选（经验/学历/薪资/类型）+ 左侧列表滚动懒加载累积岗位
- 🤖 **AI 匹配分析**：基于个人简历按可自定义评分维度加权评分（技术栈/经验/方向/薪资/工作制度等）
- 🎮 **两种运行模式**：全自动（AI 评估后自动发起 BOSS 沟通）/ 半自动（AI 分析后进审核列表，人工确认再沟通）
- ⭐ **超预期岗位收藏**：匹配度 ≥ 超预期阈值的岗位自动入库，独立页面查看（含 BOSS 网址/公司规模/是否上市/行业）
- 🚫 **低质量岗位黑名单**：劳务外包 / 岗位名与JD不符 / 远超简历 自动分级拉黑（永久/短期/观察），重复遇到直接跳过，不再读 JD、不调 AI
- 📊 **Web 控制面板**：在线改配置、管理简历、实时日志、统计面板、人工审核
- 🛡️ **浏览器控制**：通过 KIMI Webbridge 扩展操作已登录浏览器，并限制发送频率

> ⚠️ **免责声明**：本项目仅供学习研究使用。请遵守 BOSS 直聘的用户协议与当地法律法规，控制投递频率（默认 3-8 秒随机间隔、每小时/每日上限），因使用本工具造成的一切后果由使用者自行承担。

## 🚀 快速开始

### 1. 克隆项目

```bash
git clone <你的仓库地址>
cd boss自动投递
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 准备配置文件

复制示例模板（Windows / macOS / Linux）：

```bash
copy config.example.json config.json        # macOS/Linux: cp config.example.json config.json
copy resume.example.json resume.json        # macOS/Linux: cp resume.example.json resume.json
copy .env.example .env                      # macOS/Linux: cp .env.example .env
```

### 4. 填写配置

- **`.env`**：填入模型 API Key、兼容 OpenAI 的 API 地址和模型名；需要本机代理时可设 `AI_HTTP_PROXY`，例如 `http://127.0.0.1:7897`
- **`config.json`**：搜索关键词、意向城市、匹配阈值、评分维度、黑名单策略等
- **`resume.json`**：你的个人信息、技能、实习/项目经历、期望薪资（AI 评分依据）

> 📝 也可以在控制面板网页中在线修改这些配置，无需手编 JSON。

### 5. 启动浏览器扩展

1. 安装 [KIMI Webbridge](https://chromewebstore.google.com/) 浏览器扩展（`chrome.debugger` API 控制浏览器）
2. 打开 Edge / Chrome 浏览器，保持扩展启用
3. 脚本通过 WebSocket（默认 `ws://127.0.0.1:10086/ws`）与扩展通信，扩展每 30 秒自动重连

### 6. 运行

**方式一：Web 控制面板（推荐）**

```bash
python app.py
```

双击 `一键自动投递.bat` 后，浏览器会打开 `http://localhost:5000`，引擎自动进入全自动模式。面板仍可暂停或停止。

当前自动模式使用浏览器中已登录的 BOSS 账号；控制面板显示启动时核对的账号姓名和时间。匹配岗位后点击「立即沟通」，确认平台默认招呼已发送；随后核对会话的公司和岗位，发送根据简历与 JD 中共同技能生成的简短介绍。脚本从本地控制面板上传记录读取附件文件名，只选择 BOSS 账号中同名的附件简历。BOSS 网页端在双方回复前可能禁用「发简历」，因此脚本会保留待发送记录，搜索结束后每 5 分钟检查一次；按钮可用时选择该附件并核对「已发送给Boss」回执。历史记录会显示每条会话最近的等待或失败原因；发送结果不明时需人工核对，脚本不会盲目重发。请保持控制面板和浏览器运行，点击「停止」会结束等待及每日自动搜索。

直接双击项目目录中的 `一键自动投递.bat`：它会启动 Chrome（若未打开）、启动本地面板并自动开始投递；重复双击会复用已有面板，不会开第二个投递引擎。直接运行 `app.py` 也会自动开始。启动前会核对 BOSS 网页账号姓名，附件名称在实际发送时核对。手机 BOSS App 登录同一账号后，在「消息」中查看电脑端发起的沟通、回复和简历发送回执。

桌面 PDF 上传到本地控制面板仅用于 AI 匹配，不等于上传到 BOSS 账号。请先在 BOSS 网页「简历 → 附件管理」上传同名文件。`results/applied_*.json` 记录已确认沟通；`results/submission_state.json` 分别记录个性化介绍与附件发送状态，避免重启后重复发送。历史沟通不会自动补发。

控制面板顶部的「📅 历史记录」打开 `/history`，可选择日期或直接点击有记录的日期查看当天匹配、确认沟通、介绍消息和 PDF 已发送次数，并查看每条岗位最新核查结果。历史数据保存在 `data/boss_jobs.db`，首次升级会从 `results/` 的旧 JSON 自动导入，重启后仍可查询。沟通按确认日期统计，介绍和 PDF 按各自实际发送日期统计；早期未记录发送阶段的岗位显示「旧记录未统计」。招聘方回复和面试邀请目前不计入。

搜索配置可逐行添加城市及税前月薪下限、上限（K），例如北京 10–15K、杭州 8–10K；上限可留空。筛选以岗位显示的**月薪下限**落在本城市设置区间内为准，不折算 13/14 薪，无法确认月薪的岗位不自动沟通。保存按钮会从服务器重新读取配置并反馈是否成功；城市列表和页数在下次搜索时生效。启动时立即搜索一次；默认每天本机时间 09:00 再搜索，可在网页修改时间或关闭。个性化介绍优先引用简历中已有的项目成果，再补充与 JD 重合的技能；已发送的旧消息不会因模板调整而重发。岗位按稳定 ID 去重，链接中的临时参数变化不会让同一岗位重复分析。

外包预筛关键词也能在网页修改。命中后会直接永久拉黑岗位，建议检查“外包”“驻场”等宽泛词是否符合你的筛选意图；已存黑名单不会因修改关键词自动清除。

控制面板提供「企业工商核验」入口，打开国家企业信用信息公示系统。该系统向公众提供实名网页查询；没有找到可供本地脚本直接调用的开放接口。工商全称和统一社会信用代码必须先与 BOSS 招聘主体核对，实缴及参保数据的缺失不会自动认定为违规；年报参保人数也不能证明特定岗位的社保与公积金缴纳情况。

**方式二：命令行启动同一控制面板**

```bash
python main.py
```

`main.py` 是兼容入口，与 `app.py` 使用同一个引擎；不再运行旧版独立投递流程。

半自动模式的待审核岗位和已批准待执行岗位会保存在本机 `results/`。搜索结束后，只要仍有待审核岗位或待补发会话，引擎会继续等待后续处理。浏览器发送结果不明确时会标为“需人工核对”，不会自动重复发送。

### 7. 登录

- 脚本自动检测登录状态，未登录时会在浏览器打开 BOSS 直聘登录页
- 用手机 BOSS 直聘 App 扫码登录
- 之后保持浏览器打开，扩展持续连接

## 🖥️ Web 控制面板

| 功能 | 说明 |
|------|------|
| 🎮 启动/暂停/停止 | 控制引擎运行 |
| 🔧 在线改配置 | 关键词、城市、阈值、最低月薪、排除标题词及网页筛选条件一键保存 |

| 👤 半自动模式 | AI 搜索入审核列表，人工决定沟通/跳过/拉黑 |
| 🤖 全自动模式 | AI 筛选后沟通、发个性化介绍，双方回复后补发指定 PDF 并核对回执 |
| 📜 实时日志 | 浏览器实时查看运行状态 |
| 📅 历史记录 | 按日期查看已保存的沟通、介绍和 PDF 发送动作（`/history`） |
| ⭐ 超预期岗位 | 独立页查看收藏（`/starred`） |
| 🚫 黑名单 | 独立页查看/管理拉黑（`/blacklist`） |

## ⚙️ 主要配置项

| 配置 | 说明 | 默认 |
|------|------|------|
| `search.keyword` / `search.city` | 搜索关键词 / 意向城市 | AI应用开发 / 空 |
| `search.daily_search_time` | 每日再次搜索的本机时间；留空关闭 | 09:00 |
| `ai.match_threshold` | 匹配度阈值（≥ 投递） | 60 |
| `ai.over_match_threshold` | 超预期阈值（≥ 收藏） | 80 |
| `scoring.dimensions` | 评分维度（名称/权重/说明/启用） | 5 个默认维度 |
| `application.max_per_hour` / `daily_limit` | 每小时 / 每日沟通上限 | 5 / 10 |
| `application.delay_range_seconds` | 操作间隔（模拟人类） | [3, 8] |
| `blacklist.enabled` | 低质岗位自动拉黑 | true |

完整配置说明见 `CLAUDE.md`。

## 📁 项目结构

```
boss自动投递/
├── app.py              # Web 控制面板服务器
├── main.py             # CLI 命令行版
├── boss_engine.py      # 后台引擎（启动/暂停/停止/人工干预）

├── database.py         # SQLite（投递历史 + 超预期收藏 + 黑名单）
├── config.py           # 配置读取/校验
├── webbridge_client.py # KIMI Webbridge WebSocket 客户端
├── utils.py            # 工具函数（延时/日志/结果保存）
├── config.example.json # 配置示例模板
├── resume.example.json # 简历示例模板
├── .env.example        # API Key 示例
├── templates/          # 控制面板页面
└── results/ · logs/ · data/   # 运行产物（自动生成）
```
